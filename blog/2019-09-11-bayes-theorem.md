贝叶斯公式核心是，知道某一条件概率后，找出这个条件发生的原因。也叫逆条件概率。

举个栗子：我们知道了B发生后A发生的概率P(A\|B)，由此我们可以用贝叶斯公式推出A发生后B发生的概率。

贝叶斯公式可以根据条件概率和全概率公式推导出来。在推导之前有个前提假设：Ai概率事件是某一个完备概率组中的事件，该完备事件组有n个事件，Ai是其中一个。1\<=i\<=n（如A事件与非A事件，这两事件就能构成一个完备事件组）

![](/img/wordpress-archive/2019/09/image-21.png)

**推导过程如下：**

根据条件概率有：

**原式 =** P(B\[i\]\|A) = P(B\[i\]A) / P(A)

将B事件与A事件所属的完备概率组做全概率公式后，将P(A)展开得：

P(B\[i\]\|A) = P( B\[i\]A ) / ( P(A\|B\[1\])P(B\[1\]) + P( A\|B\[2\])P(B\[2\] ) +······+P( A\|B\[n\])P(B\[n\] ) )

此时我们可看出，我们求的是P(B\[i\]\|A)，而分母已经全被我们转化成了P(A\|B\[i\])的条件。

接下来我们利用条件概率将分子也转化成P(B\|A)的条件样式

即：P(BA) =  **P(B) P(A\|B)** =  P(A) P(B\|A)

所以继续转化原式分子( **P( B\[i\]A )····\>P(B\[i\])P(A\|B\[i\])**)得：

P(B\[i\]\|A) =  P(B\[i\])P(A\|B\[i\]) /   ( P(A\|B\[1\])P(B\[1\]) + P( A\|B\[2\])P(B\[2\] ) +······+P( A\|B\[n\])P(B\[n\] ) )

最后这个公式就是贝叶斯公式。
